Project explores real-time hand gesture recognition using computer vision and machine learning.

### Objective:
compare performance of different architectures performance on hand landmark data extracted from video input. Project focuses on trade-offs between model complexity, inference speed and accuracy in real time setting.

### Practcal use: 
webapp controlled with 4 gestures.
LINK: https://activehandgesturesdetectio-tdumq5f3xec9yghbnhnwpb.streamlit.app/

### Pipeline overview
Camera Feed -> MediaPipe Hand Tracking -> Landmark Extraction -> Feature Preprocessing -> Classification Model -> Real-Time Prediction

### Dataset
The dataset was created from approximately 80 self-recorded videos containing 4 gesture classes: swipe up, swipe down, click, none

### Models Section
Models for the project
1D Convolutional Neural Networks
